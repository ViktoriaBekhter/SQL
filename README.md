# SQL
Кейсы SQL

В данном файле представлено 5 кейсов SQL, написаных на программе DBeaver с использованием базы данных PostgreSQL. 
В кейсах были выполнены следующие задачи:
1. Написала запросы с использованием подзапросов, CTE, JOIN, фильтрации, агрегатных
функций, сортировки, группировки и др.
2. Строила запросы с помощью оконных функций.
3. Создавала материализованное представление и запросы для его обновления.
